# Landing Page Images

This directory should contain the following images for the landing page:

## Required Images:

1. **bird.png** - Main product image (hero section)
   - Should be placed in `/public/` (root of public directory)
   - Referenced as `/bird.png` in the component

2. **mask-group.png** - Product image for story section
   - Place in `/public/images/mask-group.png`
   - Referenced as `/images/mask-group.png`

3. **Feature Section Images:**
   - `/images/rectangle-35.svg` - Header background for feature 1
   - `/images/s0087-25-0.png` - Feature 1 image (アミノ酸)
   - `/images/rectangle-35-2.svg` - Header background for feature 2
   - `/images/s0077-26-0.png` - Feature 2 image (ラムネ風味)
   - `/images/image.svg` - Header background for feature 3
   - `/images/s0083-26-0-1.png` - Feature 3 image (水無し摂取)
   - `/images/rectangle-35-3.svg` - Header background for feature 4
   - `/images/s0083-4-0-1.png` - Feature 4 image (NMN配合)

## Image Sources:

These images should be copied from the original HTML project's `img/` folder to this directory structure.
